integrals of inverse circular functions

We can find \(\displaystyle{\int \arcsin x\,\mathrm{d}x}\) using an area argument. The region under \(\displaystyle{y = \arcsin x}\) from \(\displaystyle{x=0}\) to \(\displaystyle{x=a}\) can be related to the area of a rectangle minus a complementary curved region.

What is the area of the shaded rectangle (pink and green together)?

What is the pink shaded area?

What is the green shaded area?

\[\text{rectangle area} = a\arcsin a\]
\[\text{pink area} = \int_0^{\arcsin a}\!\sin y\,\mathrm{d}y = \Big[-\cos y\Big]_0^{\arcsin a}\]
\[\phantom{\text{pink area}} = -\cos(\arcsin a) + 1 = 1 - \sqrt{1-a^2}\]
\[\int_0^a \arcsin x\,\mathrm{d}x = a\arcsin a - \left(1 - \sqrt{1-a^2}\right)\]

Use this result to find

\[\int \arcsin x\,\mathrm{d}x\]

We know that

\[\int_0^a \arcsin x\,\mathrm{d}x=a\arcsin a-1+\sqrt{1-a^2}\]

and since the \(1\) is just a constant, the indefinite integral is simply

\[\int \arcsin x\,\mathrm{d}x = x\arcsin x + \sqrt{1-x^2} + c\]

Find \(\displaystyle{\displaystyle\int \arccos x\,\mathrm{d}x}\) using an area argument.

\[\text{pink rectangle area}= x\arccos x\]
\[\text{green area}=\int_{\arccos x}^{\pi/2}\cos y\,\mathrm{d}y = \Big[\sin y\Big]_{\arccos x}^{\pi/2} = 1 - \sin(\arccos x) = 1 - \sqrt{1-x^2}\]
\[\Rightarrow\, \int_0^x \arccos x\,\mathrm{d}x = x \arccos x+ \left(1 - \sqrt{1-x^2}\right)\]
\[\Rightarrow\, \int \arccos x\,\mathrm{d}x = x\arccos x - \sqrt{1-x^2} + c\]

Use the area argument to find \(\displaystyle{\displaystyle\int \arctan x\,\mathrm{d}x}\).

\[\text{rectangle area}= x\arctan x\]
\[\text{pink area} =\int_0^{\arctan x}\!\tan y\,\mathrm{d}y = \Big[\ln\sec y\Big]_0^{\arctan x} = \ln\sec(\arctan x)\]
\[\sec(\arctan x) = \sqrt{1+x^2}, \;\text{so } \ln\sec(\arctan x) = \tfrac{1}{2}\ln(1+x^2)\]
\[\text{green area}= \int_0^x \arctan x\,\mathrm{d}x = x\arctan x - \tfrac{1}{2}\ln(1+x^2)\]

Use integration by parts to find \[\displaystyle{\int\arcsin x\,\mathrm{d}x}\]

\[u = \arcsin x\qquad \frac{\textrm{d}v}{\textrm{d}x}=1\]
\[\frac{\textrm{d}u}{\textrm{d}x}=\frac{1}{\sqrt{1-x^2}}\qquad v=x\]
\[\begin{aligned}\int\arcsin x\,\mathrm{d}x &=uv-\int v\frac{\textrm{d}u}{\textrm{d}x}\;\textrm{d}x\end{aligned}\]
\[\begin{aligned}\phantom{\int\arcsin x\,\mathrm{d}x} &=x\arcsin x-\int \frac{x}{\sqrt{1-x^2}}\,\textrm{d} x\end{aligned}\]
\[\begin{aligned}\phantom{\int\arcsin x\,\mathrm{d}x} &= x\arcsin x + \sqrt{1-x^2} + c\end{aligned}\]

Use integration by parts to find \[\displaystyle{\int\arccos x\,\mathrm{d}x}\].

\[u = \arccos x\qquad \frac{\textrm{d}v}{\textrm{d}x}=1\]
\[\frac{\textrm{d}u}{\textrm{d}x}=-\frac{1}{\sqrt{1-x^2}}\qquad v=x\]
\[\begin{aligned}\int\arccos x\,\mathrm{d}x &=uv-\int v\frac{\textrm{d}u}{\textrm{d}x}\;\textrm{d}x\end{aligned}\]
\[\begin{aligned}\phantom{\int\arccos x\,\mathrm{d}x} &=x\arccos x+\int \frac{x}{\sqrt{1-x^2}}\,\textrm{d} x\end{aligned}\]
\[\begin{aligned}\phantom{\int\arccos x\,\mathrm{d}x} &= x\arccos x -\sqrt{1-x^2} + c\end{aligned}\]

Use integration by parts to find \[\displaystyle{\int\arctan x\,\mathrm{d}x}\].

\[u = \arctan x\qquad \frac{\textrm{d}v}{\textrm{d}x}=1\]
\[\frac{\textrm{d}u}{\textrm{d}x}=\frac{1}{1+x^2}\qquad v=x\]
\[\begin{aligned}\int\arctan x\,\mathrm{d}x &=uv-\int v\frac{\textrm{d}u}{\textrm{d}x}\;\textrm{d}x\end{aligned}\]
\[\begin{aligned}\phantom{\int\arctan x\,\mathrm{d}x} &=x\arctan x+\int \frac{x}{1+x^2}\,\textrm{d} x\end{aligned}\]
\[\begin{aligned}\phantom{\int\arctan x\,\mathrm{d}x} &= x\arctan x +\frac{1}{2}\ln\left(1+x^2\right)+ c\end{aligned}\]
