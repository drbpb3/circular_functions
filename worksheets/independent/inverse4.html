Welcome to inverse circular functions: differentiation from the definition

We can differentiate \(\arcsin x\) using implicit differentiation. Here we take a different approach — working directly from the definition of the derivative and using the sine addition formula to handle the limit.

We can also differentiate the inverse circular functions more directly using the definition of a differential.

Using the fact that

\[\sin(A + B) = \sin A\cos B + \cos A\sin B\]

and putting \(A = \arcsin a\) and \(B = \arcsin b\), find \(\sin\left(\arcsin a + \arcsin b\right)\) in terms of \(a\) and \(b\), without using \(\sin\) or \(\cos\) in your expression.

Hence find \(\arcsin a + \arcsin b\).

Find \(\sin\left(\arcsin a + \arcsin b\right)\) and hence \(\arcsin a + \arcsin b\).

Press Space to reveal each step

\[\begin{aligned} \sin(A + B) &= \sin A\cos B + \cos A\sin B \\[6pt] A=\arcsin& \,a\quad\text{and}\quad B=\arcsin b\\[6pt] \Rightarrow\quad\sin(\arcsin a + \arcsin b) &= \sin(\arcsin a)\cos(\arcsin b) + \cos(\arcsin a)\sin(\arcsin b) \\[6pt] &= a\sqrt{1 - b^{2}} + b\sqrt{1 - a^{2}} \\[10pt] \Rightarrow\quad\arcsin a + \arcsin b &= \arcsin\left(a\sqrt{1 - b^{2}} + b\sqrt{1 - a^{2}}\right) \end{aligned}\]

although this isn't quite right if \(\arcsin a+\arcsin b\gt\frac{\pi}{2}\) or \(\le-\frac{\pi}{2}\)

In these cases, we have \[\begin{aligned} \arcsin a + \arcsin b&=\pm\pi- \arcsin\left(a\sqrt{1 - b^{2}} + b\sqrt{1 - a^{2}}\right) \end{aligned}\]

Find \(\cos\left(\arcsin a + \arcsin b\right)\) and hence \(\arccos a + \arccos b\).

Find \(\cos\left(\arcsin a + \arcsin b\right)\) and hence \(\arccos a + \arccos b\).

Press Space to reveal each step

\[\begin{aligned} \cos(A+B)&=\cos(\arcsin a)\cos(\arcsin b)-ab\\[12pt] &=\sqrt{1-a^2}\sqrt{1-b^2}-ab\\[12pt] \Rightarrow \arccos a+\arccos b&=\arccos\left(\sqrt{(1-a^2)(1-b^2)}-ab\right)\\[12pt] \end{aligned}\]

Putting \(c=\cos A\) and \(d=\cos B\), find \(\cos (A+B)\) and hence find \(\arccos c + \arccos d\).

Putting \(c=\cos A\) and \(d=\cos B\), find \(\cos (A+B)\) and hence find \(\arccos c + \arccos d\).

Press Space to reveal each step

\[\begin{aligned} \cos(A+B)&=cd-\sin(\arccos c)\sin(\arccos d)\\[12pt] &=cd-\sqrt{1-c^2}\sqrt{1-d^2}\\[12pt] \Rightarrow \arccos c+\arccos d&=\arccos\left(cd-\sqrt{(1-c^2)(1-d^2)}\right)\\[12pt] \end{aligned}\]

Putting \(u=\tan A\) and \(v=\tan B\), find \(\tan (A+B)\) and hence find \(\arctan u + \arctan v\).

Putting \(u=\tan A\) and \(v=\tan B\), find \(\tan (A+B)\) and hence find \(\arctan u + \arctan v\).

Press Space to reveal each step

\[\begin{aligned} \tan(A+B)&=\frac{\tan A+\tan B}{1-\tan A\tan B}=\frac{u+v}{1-uv}\\[12pt] \Rightarrow \arctan u+\arctan v&=\arctan\frac{u+v}{1-uv} \end{aligned}\]

differentiating \(\boldsymbol{\arcsin x}\) from the definition

(a)   Use the identity above to find \(\sin\left(\arcsin(x + h) - \arcsin x\right)\) in terms of \(x\) and \(h\), without \(\sin\) or \(\cos\).

(b)   Put \(\theta(h) = \sin\left(\arcsin(x + h) - \arcsin x\right)\). Find

\[\lim_{h \to 0}\frac{\theta(h)}{h}\]

(c)   Find

\[\lim_{h \to 0}\frac{\arcsin\,\theta(h)}{\theta(h)}\]

(d)   Hence find

\[\lim_{h \to 0}\frac{\arcsin\,\theta(h)}{h}\]

(e)   Now let \(f(x) = \arcsin x\). Explain why \(\arcsin(x+h) - \arcsin x = \arcsin\,\theta(h)\), and hence find \(f'(x)\) and \(\dfrac{\mathrm{d}}{\mathrm{d}x}\arcsin x\).

(a) Find \(\theta(h)\).    (b) Find \(\displaystyle\lim_{h\to 0}\dfrac{\theta(h)}{h}\).

(a)   Applying the subtraction formula with \(A = \arcsin(x+h)\) and \(B = \arcsin x\):

\[\theta(h) = (x+h)\sqrt{1-x^{2}} - x\sqrt{1-(x+h)^{2}}\]

(b)

\[\begin{aligned} \frac{(x+h)\sqrt{1-x^{2}} - x\sqrt{1-(x+h)^{2}}}{h} &= \sqrt{1-x^{2}} + x\cdot\frac{\sqrt{1-x^{2}} - \sqrt{1-(x+h)^{2}}}{h} \\[6pt] &= \sqrt{1-x^{2}} + x\cdot\frac{1-x^{2}-\bigl(1-(x+h)^{2}\bigr)}{h\bigl(\sqrt{1-x^{2}}+\sqrt{1-(x+h)^{2}}\bigr)} \\[6pt] &= \sqrt{1-x^{2}} + x\cdot\frac{2xh+h^{2}}{h\bigl(\sqrt{1-x^{2}}+\sqrt{1-(x+h)^{2}}\bigr)} \\[6pt] &\to \sqrt{1-x^{2}} + x\cdot\frac{2x}{2\sqrt{1-x^{2}}} \quad\text{as }h\to 0 \\[6pt] &= \sqrt{1-x^{2}} + \frac{x^{2}}{\sqrt{1-x^{2}}} = \frac{1}{\sqrt{1-x^{2}}} \end{aligned}\]

(c) Find \(\displaystyle\lim_{h\to 0}\dfrac{\arcsin\,\theta(h)}{\theta(h)}\).    (d) Hence find \(\displaystyle\lim_{h\to 0}\dfrac{\arcsin\,\theta(h)}{h}\).    (e) Find \(f'(x)\) where \(f(x) = \arcsin x\).

(c)   As \(h\to 0\), \(\theta(h)\to 0\). Since \(\displaystyle\lim_{u\to 0}\frac{\arcsin u}{u} = 1\):

\[\lim_{h\to 0}\frac{\arcsin\,\theta(h)}{\theta(h)} = 1\]

(d)

\[\lim_{h\to 0}\frac{\arcsin\,\theta(h)}{h} = \lim_{h\to 0}\frac{\theta(h)}{h}\times\lim_{h\to 0}\frac{\arcsin\,\theta(h)}{\theta(h)} = \frac{1}{\sqrt{1-x^{2}}}\times 1 = \frac{1}{\sqrt{1-x^{2}}}\]

(e)   Since \(\theta(h) = \sin\left(\arcsin(x+h)-\arcsin x\right)\), applying \(\arcsin\) to both sides gives \(\arcsin\,\theta(h) = \arcsin(x+h) - \arcsin x\) (the principal values agree for small \(h\)). Therefore:

\[\begin{aligned} f'(x) &= \lim_{h\to 0}\frac{\arcsin(x+h)-\arcsin x}{h} = \lim_{h\to 0}\frac{\arcsin\,\theta(h)}{h} = \frac{1}{\sqrt{1-x^{2}}} \end{aligned}\] \[\boxed{\dfrac{\mathrm{d}}{\mathrm{d}x}\arcsin x = \dfrac{1}{\sqrt{1-x^{2}}}}\]

Congratulations!

You have differentiated \(\arcsin x\) directly from the definition of the derivative, without using implicit differentiation. The sine addition formula was the key — it let you rewrite \(\arcsin(x+h) - \arcsin x\) as \(\arcsin\,\theta(h)\), where \(\theta(h)\) is an expression whose limit you could compute directly.

The result \(\dfrac{\mathrm{d}}{\mathrm{d}x}\arcsin x = \dfrac{1}{\sqrt{1-x^{2}}}\) emerges cleanly once the right substitution is in place.
