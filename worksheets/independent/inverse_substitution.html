integrals using inverse circular functions

Find the shaded area.

\(\dfrac{\mathrm{d}}{\mathrm{d}x}\arcsin x\) \(=\) \(\dfrac{1}{\sqrt{1-x^2}}\)
\(\implies\,\displaystyle\int \dfrac{1}{\sqrt{1-x^2}}\;\mathrm{d}x\) \(=\) \(\arcsin x+c\)
\(\implies\,\text{area}\) \(=\) \(\displaystyle\int_0^1 \dfrac{1}{\sqrt{1-x^2}}\;\mathrm{d}x\)
\(=\) \(\bigg[\arcsin x\bigg]_0^1\)
\(=\) \(\dfrac{\pi}{2}\)

Use the substitution \(\displaystyle{u = \arcsin x}\) for the integral \[\int \frac{1}{\sqrt{1-x^2}}\;\mathrm{d}x\]

\(u = \arcsin x \implies\,\dfrac{\mathrm{d}u}{\mathrm{d}x}\) \(=\) \(\dfrac{1}{\sqrt{1 - x^{2}}}\)
\(\displaystyle\int\dfrac{1}{\sqrt{1 - x^{2}}}\;\mathrm{d}x\) \(=\) \(\displaystyle\int\dfrac{1}{\sqrt{1 - x^{2}}}\,\dfrac{\mathrm{d}x}{\mathrm{d}u}\mathrm{d}u\)
\(=\) \(\displaystyle\int\dfrac{1}{\sqrt{1 - x^{2}}}\sqrt{1 - x^{2}}\;\mathrm{d}u\)
\(=\) \(\displaystyle\int \mathrm{d}u\)
\(=\) \(u + c\)
\(=\) \(\arcsin x + c\)

In practice, you might write the subsitution as \(\displaystyle{x=\sin u}\). Try it this way.

\(x = \sin u \implies\,\dfrac{\mathrm{d}x}{\mathrm{d}u}\) \(=\) \(\cos u\)
\(=\) \(\pm \sqrt{1 - \sin^{2}u}\)
\(=\) \(\pm \sqrt{1 - x^{2}}\)

At this point, it is really important to remember that the actual substitution is \(\displaystyle{u=\arcsin x}\) so that \(\displaystyle{\dfrac{\mathrm{d}x}{\mathrm{d}u}>0}\)

\(\displaystyle\int\dfrac{1}{\sqrt{1 - x^{2}}}\;\mathrm{d}x\) \(=\) \(\displaystyle\int\dfrac{1}{\sqrt{1 - x^{2}}}\;\dfrac{\mathrm{d}x}{\mathrm{d}u}\mathrm{d}u\)
\(=\) \(\displaystyle\int\dfrac{1}{\sqrt{1 - x^{2}}}\sqrt{1 - x^{2}}\;\mathrm{d}u\)
\(=\) \(\displaystyle\int \mathrm{d}u\)
\(=\) \(u + c\)
\(=\) \(\arcsin x + c\)

Use the subsitution \(\displaystyle{x=\cos u}\) for the integral \[\int \frac{1}{\sqrt{1-x^2}}\;\mathrm{d}x\]

\(x = \cos u \implies\,\dfrac{\mathrm{d}x}{\mathrm{d}u}\) \(=\) \(-\sin u\)
\(=\) \(\pm \sqrt{1 - \cos^{2}u}\)
\(=\) \(\pm \sqrt{1 - x^{2}}\)

At this point, it is really important to remember that the actual substitution is \(\displaystyle{u=\arccos x}\) so that \(\displaystyle{\dfrac{\mathrm{d}x}{\mathrm{d}u}<0}\)

\(\displaystyle\int\dfrac{1}{\sqrt{1 - x^{2}}}\;\mathrm{d}x\) \(=\) \(\displaystyle\int\dfrac{1}{\sqrt{1 - x^{2}}}\;\dfrac{\mathrm{d}x}{\mathrm{d}u}\mathrm{d}u\)
\(=\) \(\displaystyle{-}\int\dfrac{1}{\sqrt{1 - x^{2}}}\sqrt{1 - x^{2}}\;\mathrm{d}u\)
\(=\) \(\displaystyle{-}\int \mathrm{d}u\)
\(=\) \(-u + c\)
\(=\) \(-\arccos x + c\)

Explain why it is possible that both

\[\int \frac{1}{\sqrt{1-x^2}}\;\mathrm{d}x=\arcsin x+c\]

and

\[\int \frac{1}{\sqrt{1-x^2}}\;\mathrm{d}x=-\arccos x+c\]

Remember that

\[\arcsin x+\arccos x=\frac{\pi}{2}\]

so the two integrals differ by \(\displaystyle{\frac{\pi}{2}}\). That is, the \(c\) is different in each case.

Find the shaded area.

\(\dfrac{\mathrm{d}}{\mathrm{d}x}\arctan x\) \(=\) \(\dfrac{1}{1+x^2}\)
\(\implies\,\displaystyle\int \dfrac{1}{1+x^2}\;\mathrm{d}x\) \(=\) \(\arctan x+c\)
\(\implies\,\text{area}\) \(=\) \(\displaystyle\int_0^\infty \dfrac{1}{1+x^2}\;\mathrm{d}x\)
\(=\) \(\bigg[\arctan x\bigg]_0^\infty\)
\(=\) \(\dfrac{\pi}{2}\)

Use the substitution \(\displaystyle{x = \tan u}\) for the integral \[\int\frac{1}{1 + x^{2}}\;\mathrm{d}x\]

\(x = \tan u \implies\,\dfrac{\mathrm{d}x}{\mathrm{d}u}\) \(=\) \(\sec^{2}u\)
\(=\) \(1 + \tan^{2}u\)
\(=\) \(1 + x^{2}\)
\(\displaystyle\int\dfrac{1}{1 + x^{2}}\;\mathrm{d}x\) \(=\) \(\displaystyle\int\dfrac{1}{1 + x^{2}}\;\dfrac{\mathrm{d}x}{\mathrm{d}u}\mathrm{d}u\)
\(=\) \(\displaystyle\int\dfrac{1}{1 + x^{2}}\left( 1 + x^{2} \right)\;\mathrm{d}u\)
\(=\) \(\displaystyle\int \mathrm{d}u\)
\(=\) \(u + c\)
\(=\) \(\arctan x + c\)

Here, although the substitution is actually \(\displaystyle{u=\arctan x}\), there is no difficulty with the signs as there was before.

What are the marked angles, in terms of \(a\)?

What are the area of the green segment and the area of the pink triangle?

\(\text{green area}\) \(=\) \(\dfrac{1}{2}\arcsin a\)
\(\text{pink area}\) \(=\) \(\dfrac{1}{2}a\sqrt{1-a^2}\)

Use these results to find \[\int_0^a\sqrt{1-x^2}\,\mathrm{d}x\]

\(\displaystyle\int_0^a\sqrt{1-x^2}\,\mathrm{d}x\) \(=\) \(\text{green + pink areas}\)
\(=\) \(\dfrac{1}{2}\arcsin a+\dfrac{1}{2}a\sqrt{1-a^2}\)

Find \(\displaystyle{\int\sqrt{1-x^2}\,\mathrm{d}x}\) using the substitution \(\displaystyle{x = \sin u}\).

\(\dfrac{\mathrm{d}x}{\mathrm{d}u}\) \(=\) \(\cos u\)
\(\displaystyle\int\sqrt{1-x^2}\,\mathrm{d}x\) \(=\) \(\displaystyle\int\sqrt{1-\sin^2 u}\cos u\,\mathrm{d}u\)
\(=\) \(\displaystyle\int\cos^2 u\,\mathrm{d}u\)
\(=\) \(\displaystyle\int\dfrac{1+\cos 2u}{2}\,\mathrm{d}u\)
\(=\) \(\dfrac{u}{2} + \dfrac{\sin 2u}{4} + c\)
\(=\) \(\dfrac{u}{2} + \dfrac{2\sin u\cos u}{4} + c\)
\(=\) \(\dfrac{\arcsin x}{2} + \dfrac{x\sqrt{1-x^2}}{2} + c\)

Well done on completing Part 3!

You have derived the derivatives of arcsin, arccos, and arctan, used them to evaluate integrals, and differentiated arcsin directly from the definition of the derivative.
